    Design doctrine

    Scientific instrumentation for enrollment analytics.

    Most analytics dashboards answer "what should this look like" before they answer "who reads this at 7:30am before the enrollment team standup, and what decision changes as a result." Dolphin Academic Prep started with the second question. The answer was an enrollment team that needs to see program performance, session engagement, and conversion trends at a glance — without hunting through spreadsheet tabs.

    That single finding dictates almost everything here. Hairline rules instead of card shadows, because shadows imply hierarchy the data doesn't have. Tabular numerals everywhere a figure appears, because columns that don't align are columns that get misread. Color reserved strictly for state — up, down, stale, throttled — because when everything is highlighted, nothing is.

    The result should feel like a well-organized academic dashboard: dense but legible, honest about data freshness, and explicit about what the API was actually asked. No gradient hero. No 3D chart. No chartjunk.

    Delta encoding that survives deuteranopia

    Roughly one in twelve of the men in a leadership readout has a red-green color vision deficiency. Encoding direction with hue alone is a design defect, not a preference. Every delta in this console carries three redundant channels: shape (triangle up, triangle down, bar for flat), sign (an explicit + or −), and color — plus a text alternative announced to screen readers.

    Specifications

    Performance

    Five blocks render in under 900ms from cache; measured p95 is 612ms. Blocks re-render in priority order — KPIs, channels, content, geo, funnel — with 60ms stagger, so the eye lands on the headline number before the detail arrives.

    Responsiveness

    Container queries drive the data grids, not viewport breakpoints: the KPI row collapses 6 → 3 → 2 columns based on the width it actually has. The rail becomes a 64px icon strip below 1280px and an off-canvas drawer with bottom navigation below 900px.

    Accessibility

    WCAG 2.1 AA on both dark-first and light surfaces. Keyboard-navigable tables and scrubber, aria-live regions for recomputed KPIs, focus trapped in the payload drawer and command palette, and prefers-reduced-motion honored everywhere.

    Honesty

    Every block displays its source and last-refreshed timestamp. Partial states are surfaced as partial: if three blocks are live and two are degraded, the header says so rather than showing a uniformly confident page.

    Deep-linkability

    Any window and property scope serializes to ?from=&to=&cmp=&prop=. An executive can paste the exact view they're arguing about into Slack and the recipient lands on the same numbers.

    Cost legibility

    The scrubber shows projected token cost and cache coverage while dragging, and only commits a request on release. The interaction teaches the user what the pipeline is doing — quota awareness as a felt experience, not a footnote.

    We would rather show a real number with a freshness label than a polished number nobody can trace. Dolphin Academic Prep — analytics brief
